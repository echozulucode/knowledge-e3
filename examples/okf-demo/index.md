# Gravitational Waves — Demo Bundle

> A tiny, valid Open Knowledge Format (OKF v0.2) bundle for demoing Knowledge E3
> import across the web UI and MCP. Authored in pure-OKF style: every concept has
> a `type`, a `description` and exactly one primary category (`reference` — the
> importing instance curates that vocabulary), and cross-references are
> bundle-relative Markdown links. The
> [Gravitational Waves](/concepts/gravitational-waves.md) concept also shows the
> v0.2 trust families (`generated`/`verified`/`status`/`stale_after`/`sources`

## Concepts

* [Gravitational Waves](/concepts/gravitational-waves.md) - Ripples in spacetime predicted by general relativity.
* [General Relativity](/concepts/general-relativity.md) - Einstein's geometric theory of gravitation.
* [LIGO](/concepts/ligo.md) - The interferometer that first detected gravitational waves.
